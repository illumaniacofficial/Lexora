# Wave 05 — Studio OS: Canonical Project Intelligence

Status: IMPLEMENTED ON FEATURE BRANCH; PRODUCTION DEPLOYMENT PENDING FINAL GATE

Base: revival/wave-04-emergent-runtime

## Goal

Turn Lexora's hidden revival infrastructure into a visible, durable creative operating system:

Scribe creates → Redactor independently reviews → owner approves → Canon persists → continuity memory updates.

This wave deliberately reuses the existing Property/IP, Creative Target Contract, Artifact Vault, continuity snapshot, Concept Lab, and chapter approval infrastructure instead of creating parallel systems.

## Implemented

### Canon Workspace
- New top-level Canon tab in Project Detail.
- Property/IP identity and classification visibility.
- Book Genome visibility.
- Editable Creative Target Contract.
- Canonical continuity summary:
  - approved chapters
  - characters
  - accepted facts
  - world rules
  - open narrative loops
- Runtime state visibility.
- Scribe → Redactor → Owner → Core Memory workflow status.
- Artifact Vault with expandable artifact contents and state controls.

### Artifact lifecycle
- Outline generation creates a canonical book-architecture artifact.
- Editorial Board creates a redactor-review artifact.
- Owner chapter approval creates a canonical chapter-manuscript artifact.
- Approval postflight continues to create accepted continuity-delta artifacts.
- Any edit/rewrite that invalidates approval retires stale canonical manuscript state through the existing continuity invalidation path.
- Canon promotion is atomic at the artifact-state level: only one canonical artifact can exist per project/chapter/type stream; prior canonical versions become superseded.
- Rejected, superseded, and archived artifacts remain recoverable.

### Concept Lab Idea Library
- One-click Save on generated Concept Directions.
- Persistent Idea Library backed by Concept Dossiers.
- Manual Quick Capture for ideas not generated by the Triad.
- Search across title, premise, genres, topics, and tags.
- Notes, tags, favorites.
- Archive instead of delete.
- Saved generated directions preserve full Oracle/Scribe/Redactor intelligence.
- Promoting a saved generated direction into a Concept Dossier reuses the same saved record rather than duplicating it.
- Quick-captured manual ideas remain intentionally lightweight and cannot be greenlit until developed into a complete dossier.
