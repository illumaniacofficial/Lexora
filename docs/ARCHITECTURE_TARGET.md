# Lexora — Target Architecture

Status: canonical direction after Revival Waves 01-05  
Next implementation wave: Wave 06 — Boardroom + Studio Review

## Product shape

Lexora is a private creative and publishing operating system centered on a persistent Property/IP record.

The long-term hierarchy is:

Property
- Creative Target Contract
- Canon / IP Bible
- multi-value classification
- Books
- Editions
- Audio productions
- Podcast/Broadcast productions
- Adaptation branches

Each output is a branch of the same creative property rather than an isolated project.

## Permanent directors

- Core — orchestration, state, routing, approvals, recovery
- Oracle — concept, audience, market intelligence
- Scribe — planning and creation
- Redactor — independent editorial judgment
- Scholar — research/evidence
- Frame — adaptation/cinema
- Lingua — translation/localization
- Press — packaging/publishing/audio
- Atlas — catalog/performance intelligence

Director identity remains independent of a specific model provider.

## Canon and artifacts

All meaningful generations become versioned artifacts.

Canonical state is explicit:
- generated
- reviewing
- accepted
- canonical
- superseded
- rejected
- archived
- published

Rejected or superseded creative work remains recoverable.

## Runtime direction

Lexora should support:
- connected
- hybrid
- off-grid

Cloud models improve the studio but do not define the studio.

Target local-first infrastructure includes:
- local project store
- local Artifact Vault
- local canonical memory
- local model router
- queued network-required work
- conflict-safe synchronization
- explicit Blackout Mode

Full local database/sync is intentionally deferred beyond Wave 05.

## Editorial decision system

Wave 06 activates the contracts already present for:

Boardroom
1. independent director positions
2. challenge round
3. rebuttal/revision
4. Core synthesis
5. owner decision

Studio Review
- domain-specific signoffs
- unresolved critical-issue tracking
- packaging gate
- owner final approval

Press cannot begin final packaging until Studio Review is ready.

## Publishing expansion

After Boardroom/Studio Review:
- Press 2.0 publishing/release pipeline
- Lingua edition intelligence
- Audio Studio
- Narrator/Voice Lab
- Podcast/Broadcast Studio
- local-first hardening
- Frame screenplay/cinema/video branches

Book canon remains separate from adaptation canon so adaptations can restructure source material without rewriting the literary master.
